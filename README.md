# NNA Wallpaper

Live interactive HTML wallpapers for Windows — without Wallpaper Engine.

> Work in progress. The first release (v0.1.0) is being assembled; this README will be
> replaced with installation and configuration instructions.

- Windows 10 / 11, .NET 8, WebView2, WPF
- Widgets are plain HTML/JS/CSS folders with a manifest
- Local host on `127.0.0.1` provides system stats, media, launcher, weather, audio spectrum
- Optional NNA Planner block (tasks, meetings, habits, money, morning briefing)
- MIT license
